## How It Works Behind the Scenes

### Step 1️⃣: Parse Message for Expertise Signals

```
User: "Can you build me a Ryzen 7 9800X3D PC with RTX 4090?"

Signals detected:
  ✓ "Ryzen 7 9800X3D" = EXPERT signal (specific CPU model)
  ✓ "RTX 4090" = EXPERT signal (specific GPU model)
  ✓ 2 expert signals = "EXPERT" classification

Confidence: 0.85 (high confidence)
```

### Step 2️⃣: Select Question Flow

```
if (expertise === 'expert') {
  // Skip workload, usage intensity
  // Ask: CPU pref → GPU pref → Display → Budget
} else if (expertise === 'intermediate') {
  // Ask: Workload → Budget → (Display optional)
} else {
  // Ask: Workload → Usage → Budget
}
```

### Step 3️⃣: Generate Adaptive Response

```
if (expertise === 'expert') {
  response.badge = "👨‍💻 EXPERT BUILD"
  response.includes = [technical details, component swaps, TDP, VRM]
} else if (expertise === 'intermediate') {
  response.badge = "⚙️ OPTIMIZED BUILD"
  response.includes = [practical details, brand choices]
} else {
  response.badge = "👶 GUIDED BUILD"
  response.includes = [simple explanations, "why" for each part]
}
```
